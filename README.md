# 📒 Agenda de Contatos (Python)

Este é um pequeno projeto feito em **Python**, utilizando conceitos básicos de **funções**, **listas** e **dicionários**.

---

## 🚀 Funcionalidades

- Adicionar contatos  
- Listar todos os contatos  
- Buscar contatos pelo nome  
- Deletar contatos  
- Sair do programa

---

## 🧠 Conceitos usados
- Estruturas de repetição (`while`, `for`)
- Funções e dicionários
- Manipulação de listas
- Tratamento de erros (`try/except`)
